## Agent skills

### Issue tracker
Issues, specs, and tickets are tracked in GitHub Issues (`abel-fresnillo/pragvantix-website`) through the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels
Default vocabulary: two categories (`bug`, `enhancement`) and five states (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs
Single-context. See `docs/agents/domain.md`.
